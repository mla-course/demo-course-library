# Demo Courses Source Repository

This repository contains sample demo courses for testing
and demonstrates how to deploy them to Cloudflare Pages,
with required headers to enable CORS.

## Directory Structure

* `src/courses/` - Contains sample demo courses written in
  human-readable [Org-mode](https://orgmode.org/) (`.org`) format.

* `public/` contains the parsed course data in
  machine-readable [EDN](https://github.com/edn-format/edn) (`.edn`) format.
